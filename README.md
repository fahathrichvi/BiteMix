# BITE MIX — வீட்டின் சுவை, உங்கள் வாசலில்

Tamil-first landing page and WhatsApp storefront for BITE MIX (Next.js · TypeScript · Tailwind CSS).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Where to change things

| What | File |
| --- | --- |
| WhatsApp number, phone, Instagram, Facebook, site URL | `config/site.ts` |
| Products, prices, sizes, categories, badges | `data/products.ts` |
| Customer reviews | `data/testimonials.ts` |
| WhatsApp message wording | `lib/whatsapp.ts` |
| Colours and fonts | `app/globals.css` (`@theme`), `app/layout.tsx` |

The product grid, category filters, WhatsApp order messages and SEO structured data are all generated from `data/products.ts`.

## Images

The food images are illustrations generated by `scripts/generate-art.mjs` (`npm run art` regenerates the SVG sources in `scripts/art/` and renders PNGs into `public/images/` using a local Chrome/Edge).

To use real photos: put the file in `public/images/products/` (JPG/PNG/WebP, ideally 4:3, at least 1200px wide) and update that product's `image` and `imageAlt` in `data/products.ts`. Next.js serves optimised AVIF/WebP automatically.

## Contact form

There is no backend: a valid enquiry opens WhatsApp with the message pre-filled, so no API keys live in the frontend.
